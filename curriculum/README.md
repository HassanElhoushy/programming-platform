# مصادر المنهج

ضع هنا كتاب الوزارة وأي مذكرات أو صور من الكتاب.

الملفات نفسها **لا تدخل git** — الريبو عام والكتاب محفوظ الحقوق. القاعدة
في `.gitignore`، وهذا الملف وحده هو المتتبَّع.

## الترتيب الذي يسهّل العمل

```
curriculum/
  ch1-tech-society.pdf
  ch2-cybersecurity.pdf
  ch3-web-apps.pdf
  ...
```

أو صوراً لصفحات درس بعينه:

```
curriculum/ch3-lesson2/page-41.jpg
curriculum/ch3-lesson2/page-42.jpg
```

## ملاحظة عملية

قراءة كتاب كامل دفعة واحدة تستهلك الجلسة بلا طائل. الأجدى فصلٌ أو درسٌ في
كل مرة: تقول أي درس، ويُقرأ ما يخصّه وحده.
